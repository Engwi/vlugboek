start-local.ps1

Starts the local Vlugboek backend and frontend.

Local
ParameterDescriptionDefault
-Build Packages the backend before starting. Also packages automatically when the jar is missing. Off
-BackendPort Backend port used when checking whether the API is already running. 8081
-FrontendPort Frontend port used when checking whether Vite is already running. 5173
-MailerPort Mailer port used when checking whether the local PDF mailer is already running. 8788
-SkipMailer Starts only the backend and frontend, leaving the local mailer alone. Off 
.\scripts\start-local.ps1
.\scripts\start-local.ps1 -Build
.\scripts\start-local.ps1 -BackendPort 8081 -FrontendPort 5173

Local
ParameterDescriptionDefault

-Ports Ports to inspect when -AlsoStopPorts is used. 8081, 5173, 8788 
.\scripts\stop-local.ps1
.\scripts\stop-local.ps1 -AlsoStopPorts
.\scripts\stop-local.ps1 -AlsoStopPorts -Ports 8081,5173,8788

build-release.ps1

Builds and bundles the application for Linux deployment.

Release
ParameterDescriptionDefault
-Release Release identifier used in the bundle and extracted folder name. Current timestamp
-SkipBuild Skips Maven/Vite builds and bundles existing build outputs. Off 
.\scripts\build-release.ps1
.\scripts\build-release.ps1 -Release 2026-05-23-v1

Output is written to dist\deploy\vlugboek-<release>.tar.gz. Each bundle includes app\release-info.properties so /api/healthz can report version, release, build time, and git commit details.

deploy-linux.ps1

Builds, uploads, installs, starts, and health-checks Vlugboek on Ubuntu.

Deploy
ParameterDescriptionDefault
-Server SSH host or IP address. vlugboek.co.za
-User SSH username. root
-RemoteRoot Application root on the server. /opt/vlugboek
-Domain Public domain used for nginx config and public checks. vlugboek.co.za
-BackendPort Port for the Spring Boot API behind nginx. 18081
-SpringProfilesActive Spring profile to activate on the remote service. Use postgres for PostgreSQL. Blank
-DatabaseUrl, -DatabaseUser, -DatabasePassword PostgreSQL JDBC connection values passed to the remote service when using the PostgreSQL profile. Blank
-SeedReferenceData Seeds the official PWDF federation, clubs, and lofts if they do not exist. $true
-SeedPdfImport Imports bundled seed PDFs on startup. Turn off for hardened PostgreSQL production deploys. $true
-SeedAdmin, -SeedAdminEmail, -SeedAdminName, -SeedAdminPassword Controls explicit admin bootstrap seeding. Enabled with local MVP admin defaults
-SeedDemoUsers, -SeedDemoEmail, -SeedDemoName, -SeedDemoPassword Controls demo user seeding. Enabled with local MVP demo defaults
-AuthenticatedHealthCheck Runs login and authenticated dashboard checks during deployment. $true
-HealthLoginEmail, -HealthLoginPassword Credentials used when authenticated health checks are enabled. demo@vlugboek.local / demo123
-AdminHealthCheck Runs admin login plus admin-only document and organisation endpoint checks during deployment. $false
-HealthAdminEmail, -HealthAdminPassword System-admin credentials used when admin health checks are enabled. admin@vlugboek.local / admin123
-RollbackOnFailure Automatically relinks the previous release and restarts the service when a post-switch deploy check fails. $true
-BundlePath Deploy an existing bundle instead of building a new one. None
-SkipBuild Passes through to build-release.ps1 when no bundle path is supplied. Off
-SkipPublicHealthCheck Skips public HTTPS checks after remote install. Useful before DNS or SSL is ready. Off

.\scripts\deploy-linux.ps1 -Server 123.123.123.123
.\scripts\deploy-linux.ps1 -BundlePath .\dist\deploy\vlugboek-20260523-130921.tar.gz
.\scripts\deploy-linux.ps1 -SkipPublicHealthCheck

rollback-linux.ps1

Relinks the Ubuntu server to the previous or named release, restarts Vlugboek, and verifies health.

Deploy
ParameterDescriptionDefault
-Server SSH host or IP address. vlugboek.co.za
-User SSH username. root
-RemoteRoot Application root on the server. /opt/vlugboek
-Domain Domain to test through nginx after rollback. vlugboek.co.za
-BackendPort Local backend port on the server. 18081
-ServiceName systemd service name. vlugboek
-ReleaseName Optional release folder name under /opt/vlugboek/releases. When omitted, the previous symlink is used. Previous release 
.\scripts\rollback-linux.ps1
.\scripts\rollback-linux.ps1 -ReleaseName vlugboek-20260524-050832

Rollback changes the live /opt/vlugboek/current symlink and restarts the backend service.

deploy-emailer-linux.ps1

Bundles and deploys the private Vlugboek PDF mailer sidecar to Ubuntu.

Deploy
ParameterDescriptionDefault
-Server SSH host or IP address. vlugboek.co.za
-User SSH username. root
-RemoteRoot Mailer root on the server. /opt/vlugboekmailer
-ServiceName systemd service name. vlugboekmailer
-EnvPath Local mailer environment file to upload to the server. emailer\.env
-BundlePath Deploy an existing mailer bundle instead of creating a new one. None
-ExpectedPort Validates that the uploaded mailer env uses the same local port as the backend. 8788 
.\scripts\deploy-emailer-linux.ps1
.\scripts\deploy-emailer-linux.ps1 -EnvPath .\emailer\.env -ExpectedPort 8788

Deploy the mailer before the main app so deploy-linux.ps1 can read the mailer token from /opt/vlugboekmailer/shared/.env and inject it into the Spring Boot service. The script also refuses to upload placeholder mail settings, a stale mailer port, or a public mailer host. Prefer SMTP_USER/SMTP_PASSWORD; legacy Gmail env names still work.

flush-remote-db.ps1

Flushes remote Vlugboek data while preserving admin users and organisation reference records.

Danger
ParameterDescriptionDefault
-Server SSH host or IP address. vlugboek.co.za
-User SSH username. root
-RemoteRoot Application root on the remote server. /opt/vlugboek
-ServiceName Systemd service name to stop before flushing and restart afterwards. vlugboek
-Database Database mode. auto reads the remote service environment. auto
-SpringProfilesActive Optional override used when auto-detecting PostgreSQL. Blank
-DatabaseUrl, -DatabaseUser, -DatabasePassword Optional database connection overrides. Usually only needed for PostgreSQL if the systemd service does not already have them. Remote service environment
-PreserveAdminEmail Require this specific admin email to exist before flushing. Blank preserves all users with role ADMIN. Blank
-SkipBackup Skips the remote pre-flush database backup. Off
-Force Skips the local typed confirmation prompt. Off 
.\scripts\flush-remote-db.ps1
.\scripts\flush-remote-db.ps1 -PreserveAdminEmail admin@vlugboek.local
.\scripts\flush-remote-db.ps1 -Database postgres -DatabaseUrl 'jdbc:postgresql://localhost:5432/vlugboek' -DatabaseUser vlugboek -DatabasePassword 'ZeroZippo101@' -Force

This is a nuclear reset. It deletes reports, datasets, email delivery audits, and non-admin users. It keeps admin users and organisation lookup records. A remote database backup is created unless -SkipBackup is used.

save-mobile-signing-secret.ps1

Saves Android release signing settings as an encrypted local secret for the current Windows user.

Mobile
ParameterDescriptionDefault
-KeystorePath Path to the release signing keystore. C:\Development\Vlugboek\vlugboekkeystore
-KeyAlias Signing key alias. key0
-UseSamePassword Prompts once and uses the same password for the keystore and key. Off 
.\scripts\save-mobile-signing-secret.ps1 -UseSamePassword

Output is written to scripts\.secrets\mobile-signing.clixml, which is ignored by source control. The script validates the alias with keytool and uses the only alias in the keystore when there is a mismatch.

linux/install-or-update.sh

Remote Ubuntu installer uploaded and executed by deploy-linux.ps1.

Remote
InputDescriptionDefault
Argument 1 Path to the uploaded release bundle on the server. Required
Argument 2 Release name used under /opt/vlugboek/releases. Current timestamp
APP_ROOT Root deployment directory. /opt/vlugboek
DOMAIN nginx domain name. vlugboek.co.za
BACKEND_PORT Spring Boot API port behind nginx. 18081
SERVICE_NAME systemd service name. vlugboek
MAILER_ROOT Private PDF mailer root used to discover the shared mailer token. /opt/vlugboekmailer
MAILER_URL Local sidecar endpoint used by the Email PDF API. http://127.0.0.1:8788/send-document
MAILER_TOKEN Optional explicit token for the sidecar. When omitted, the installer reads MAIL_WEBHOOK_TOKEN from the mailer env file. From mailer env
AUTH_HEALTH_CHECK Runs login and authenticated dashboard checks after the service starts. true
ADMIN_HEALTH_CHECK Runs system-admin login plus admin-only endpoint checks after the service starts. false
ROLLBACK_ON_FAILURE Relinks the previous release if a post-switch deploy check fails. true 
APP_ROOT=/opt/vlugboek DOMAIN=vlugboek.co.za BACKEND_PORT=18081 \
bash install-or-update.sh /opt/vlugboek/incoming/vlugboek-release.tar.gz vlugboek-release

The remote installer creates /opt/vlugboek/releases, /opt/vlugboek/current, /opt/vlugboek/shared, the vlugboek systemd service, and the nginx site file. It also exposes /opt/vlugboek/shared/downloads at /downloads/.
